# Project One Storyboard | Text-Based Adventure Game

## Theme and Storyline

**Theme:**

Escape from the Secret Laboratory. This is an adventure game that takes place in a secret underground laboratory. The player must explore different rooms, collect important items, and avoid a dangerous security robot.

**Storyline:**

The player is a scientist trapped inside a secret underground laboratory after a security system failure. The doors are locked, and a dangerous security robot is protecting the Robot Core. To complete the mission, the player must explore the laboratory and collect six items: a keycard, a flashlight, a data drive, an access code, a power cell, and a first-aid kit. The player must collect all six items before entering the Robot Core. If the player enters the Robot Core without all six items, the security robot catches the player and the game ends. If the player collects all six items first, they can safely complete the mission and escape.

## Rooms

1. Main Hall — Starting room.
2. Security Office — Contains the keycard.
3. Storage Room — Contains the flashlight.
4. Research Lab — Contains the data drive.
5. Control Room — Contains the access code.
6. Generator Room — Contains the power cell.
7. Medical Lab — Contains the first-aid kit.
8. Robot Core — Villain room.

## Items

1. Keycard — Found in the Security Office.
2. Flashlight — Found in the Storage Room.
3. Data Drive — Found in the Research Lab.
4. Access Code — Found in the Control Room.
5. Power Cell — Found in the Generator Room.
6. First-Aid Kit — Found in the Medical Lab.


## Villain

The villain is the Security Robot. It protects the Robot Core and prevents the player from completing the mission. If the player enters the Robot Core before collecting all six items, the robot catches the player and the game ends.
